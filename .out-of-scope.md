# Out of scope for RLP

RLP is a protocol for turning corrections to AI-agent work into durable repository improvements. It is deliberately narrow. The following are explicitly out of scope:

## What RLP does not do

- **Model fine-tuning or weight updates.** RLP does not train, tune, or modify model weights. The repository is the only trainable component.
- **Ungated memory.** No vector databases, knowledge graphs, or automatic agent memory tiers. Every durable artifact is a file under source control, promoted by a human, and revertible in one PR.
- **One-off prompt engineering.** RLP is not a place to store clever prompts that worked once. A correction must recur or carry security/data-corruption risk before it is promoted.
- **Replacing existing tools.** RLP uses CI, linters, Semgrep, pre-commit, editor rules, and project-specific skills. It does not ship a custom runtime, resolver, or agent framework.
- **Auto-promotion.** No agent may decide a correction becomes durable without human approval and merge.

## What RLP does not claim

- RLP is not proven end-to-end in a controlled study. Each tier in the promotion ladder is supported by production evidence; the assembled protocol is a hypothesis being field-tested.
- RLP does not guarantee fewer mistakes. It guarantees that the same promoted mistake is prevented or steered, and that stale learnings are deleted.

## Where RLP stops

RLP captures, routes, promotes, measures, and retires learnings. It does not write your tests for you, design your architecture, or replace code review.
